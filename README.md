# 琴间 · Quiet Keys

用 Mac 的四排键盘弹钢琴，下载后即可离线使用。无需安装、注册、联网或启动服务器。

## 下载与打开

1. 点击本页绿色 **Code → Download ZIP**。
2. 解压后，双击 **index.html**，用 Safari、Chrome 或 Edge 打开。
3. 点击任意琴键或按字母键开始发声。

也可以直接下载仓库中的 `index.html`（打开文件后点击 Download raw file）。不要把 GitHub 的文件预览页当成钢琴页面。

## 操作

- 数字排、QWER 排、ASDF 排、ZXCV 排：共 47 个字母、数字和符号键直接发声。
- 下排低音，上排高音；每个按键标有对应音名。
- 支持同时按多个键弹和弦，也支持鼠标和触屏点击。
- 左右方向键：移动音区，覆盖 A0–C8 完整 88 音；切换时自动停音。
- 空格：按住延音；Esc：全部停音。
- 音量和延音也可通过页面控件调整。

## 说明

声音由浏览器现场合成，不是真钢琴录音。所有样式和程序都在一个 HTML 文件中，没有外部字体、音频或脚本依赖，不上传演奏数据。

以 Mac 实体键盘为主要使用方式。手机本地 HTML 的打开和声音行为取决于浏览器及文件预览方式，尚未在真实手机完成验证。GitHub 下载本身仍需要网络；文件下载完成后使用不依赖托管网站。

## 开发

直接编辑 `index.html` 即可，无需构建工具。`check.cjs` 使用 Node.js 检查按键映射、和弦、延音、音域边界和停音逻辑：

```sh
node check.cjs
```
